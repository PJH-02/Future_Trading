# blog_ON 오버나잇 다리 백테스트 (round13)

• 규칙: 블로그 공개 규칙(KOSDAQ SNIPER v37)의 오버나잇 다리. 외부 고정, 조정 없음
• 일봉 한계: 15:20 판단을 15:30 종가로 대체. 실거래는 15:20 시점 IBS 로 판단하므로 수치가 다를 수 있음
• 달력: 069500 거래일. 차량 결측일은 무거래 처리(건수 표기)
• 지표: 누적 Π(1+r), CAGR=누적^(252/일수)−1, 변동성 std(ddof=1)·√252(0 포함), 샤프=mean·252/vol, MDD, Calmar, 승률은 활성일 기준, 순bp는 거래당 비용 후, NW_t 는 Newey-West(lags=5)
• 급락일 = 결정일 T 의 069500 종가 수익 ≤ −1.5%. '급락일제외' 행은 그 날 신호를 0 으로 둔 수치
• 블로그 주장(장중+오버나잇 합계)과 직접 비교하지 않음. 아래는 오버나잇 다리만의 수치
• 설계/검증 구간은 사전 고정. 1x 변형과 downQ 는 사후 탐색
