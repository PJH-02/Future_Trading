# 종가 베팅·오버나잇 1차 백테스트 결과 (2026-09-29)

- 대상: KODEX 200(069500) 당일 종가(장후 시간외 종가 체결 가정) 매수 → 익일 시가 매도. K6만 당일 시가 매수 → 당일 종가 매도
- 가격: 네이버 siseJson 분배 수정주가(`../../data/etf/`)
- 판정 구간: 번인 후 ~ 2025-06-05. 하위 구간 A(~2019), B(2020~2025-06). 2025-06-09 이후(E4)는 보고만 한다
- 비용: 왕복 5bp(스트레스 7bp)
- 판정 기준(모두 충족해야 통과):
    - Δ(신호 밤 평균 − 비신호 밤 평균) > 0, Newey-West(lag 5) 단측 p × 5 < 0.05
    - 7bp 차감 후 순평균 > 0 (K5 거부권은 '경보 밤 평균 < 5bp')
    - A·B 구간 모두 Δ > 0 이고 B ≥ 0.5·A
    - 연도 층화 플라시보 p ≤ 0.05
    - 변동성 조정 Δ > 0
    - 이웃 파라미터 부호 동일, 이전 자산 부호 동일, 통제 회귀에서도 유지
- 규칙은 실행 전에 각 스크립트 docstring 에 고정했다. 모든 시행 기록은 `ledger.csv` 에 있다
