## 1. 바꾼 체결 규약

• 코스피 아침 C3(K_B)·코스닥 아침 C3Q(Q_B)
  · 원형: 09:00 단일가로 신호 확정, 같은 09:00 가격에 체결, 15:30 종가 청산.
  · 실행판: 09:00 단일가(09:01 봉 시가)로 신호 확정 → 09:01:00 첫 연속 체결(09:02 봉 시가) 진입 → 15:19:00(15:20 봉 시가) 청산.
  · 09:01 봉 거래량 0 이면 그날 쉼(W_all: K_B 2026.6.8, Q_B 2026.1.2 각 1일). 09:02 봉 거래량 0 이면 다음 거래 봉 시가로 민다(0건). 15:20 봉 거래량 0 이면 15:30 단일가(0건).
  · 비중 x = 13차 series |pos| 그대로(VT30, 최대 2). x ≤ 1 은 1배 ETF(069500·229200) x 배, 1 < x ≤ 2 는 (x−1)×2배 ETF(122630·233740) + (2−x)×1배 ETF. 수익은 TOSS 1분봉 원가격 안에서만 잰다.
  · 15차 k 1.40 에서 명목이 2 를 넘는 몫(선물)은 1배 ETF 의 09:02→15:20 체결 수익으로 근사(선물 왕복 1.8bp, 틱 없음). 2022.11.23 전(W_long 만)은 (1+oc)/(1+m)/(1+e) − 1 근사, m = 첫 1분 평균 변화, e = W_all 활성일 평균(15:30 종가 / 15:19:00 시가 − 1).
  · 근사 계수(bp) K_B m / e: +16.4·+20.0 / −2.25·−2.71. Q_B m / e: +17.2·+22.1 / −3.94·−6.03.
• 코스닥 밤 ETF판(Q_A, 13차 장부)
  · 원형: 15:30 종가로 IBS 계산, 같은 종가에 체결, 다음날 시가 청산.
  · 실행판: 229200 의 09:01~15:20 봉 고가·저가와 15:20 봉 종가로 IBS20 계산(15:20 확정) → 15:30 단일가(15:30 봉 종가) 체결 → 다음날 09:00 단일가(09:01 봉 시가) 청산. 손익 날짜 = 청산일.
  · IBS20 < 0.3 ∧ 전일 종가 > 전일까지 MA10 → 233740 현금 1(명목 2). IBS20 > 0.7 ∧ 전일 종가 < MA10 → 251340 현금 1(명목 −1). MA10·전일 종가는 229200 원가격 일봉.
  · 특수일 7일(늦은 개장·수능일, 사전 공지 일정) 신호 제외. 청산일 09:01 봉 거래량 0 이면 그 밤 제외(3건). 16차 캐시 QA_bm 과 net 일치.
