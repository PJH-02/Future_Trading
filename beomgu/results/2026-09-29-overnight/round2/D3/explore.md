# D3 국면 조건 — 탐색·설계 메모 (A 구간 전용)

작성 2026-09-29 · 대상 KODEX 200(069500) 오버나잇 r_on(T) = O(T+1)/C(T) − 1 · 비용 왕복 5bp(스트레스 7bp)
질문: 추세·변동성·수급·미국 국면에 따라 오버나잇 기대수익이 갈리는가, 단순한 게이트(변수 1~2개, 임계 = 과거 창 분위)로 매일 보유보다 순샤프·MDD 를 낫게 만들 수 있는가.

## 0. 자료 가드와 규약

- 신호→수익률 관계는 결정일 T ≤ 2019-12-31 로만 계산했다. 가격은 2020-01-02(A 마지막 밤 T=2019-12-30 의 청산 시가)까지만 읽었고, 투자자별·S&P500 은 2019-12-31 까지로 잘랐다. B(2020-01-01~2025-06-05)·E4(2025-06-09~) 수익률은 한 번도 계산하지 않았다.
- B·E4 는 원자료 존재만 확인: KODEX 200 ~2026-09-29, S&P500 종가 ~2026-09-21(마지막 행 종가 결측 → dropna), 코스피 투자자별 ~2026-09-23(2020 이후 외인 결측 0).
- 고정 셀의 게이트 값(수익률 아님)이 B·E4 에도 있는지 확인했다: RVON 결측 0, USRV 결측 1(2026-09-29, SPX 캐시가 갱신되기 전이라 간격 7일 초과). 전체 이력으로 계산한 게이트와 A 까지 자른 자료로 계산한 게이트는 A 구간에서 완전히 같다(미래 정보 누수 없음).
- 설계 창: 2010-01-04 ~ 2019-12-30 (2,466밤). 하위 구간 H1 = 2010~2014, H2 = 2015~2019.
- 2004~2009 는 A 규칙(≤2019) 안의 자료라서, 후보를 추린 뒤 "사전표본" 점검용으로만 조회했다(선정 기준에는 넣지 않음).
- 국면 변수 x(T) 는 모두 T−1 종가까지의 정보(+ T 시가에 확정되는 r_on(T−1), T 09:00 이전에 끝난 미국 세션)만 쓴다. 게이트는 T 장 시작 무렵 확정된다. 진입은 T 종가 단일가, 청산은 T+1 시가 단일가이고 시간외 종가 가정은 필요 없다.
- 표준화: pct(T) = [#{x(T−k) < x(T)} + 0.5·#{x(T−k) = x(T)}] / W, k = 1..W, W = 250(T 제외 과거 창, 하나라도 결측이면 NaN). 미국 변수는 미국 세션 창으로 백분위를 낸 뒤, 한국 T 에 D < T 인 마지막 미국 세션 값을 붙였다(간격 7일 초과면 NaN).
- 지표: Δ = 평균(보유 밤) − 평균(비보유 밤), Newey-West(5) t. 순샤프·MDD·CAGR 은 engine.stats 로 계산한다(일별 = 포지션·r − 포지션·비용, 전체 표본 밤 기준, √252 연율화).

## 1. 1단계: 국면 변수 10개의 5분위 프로파일 (변형 12)

변수 정의(T−1 기준):
- TR200 = C(T−1)/MA200 − 1
- MOM20·MOM60 = C(T−1)/C(T−21·T−61) − 1
- RVON20 = SD(r_on 직전 20밤)
- RVOC20 = SD(r_oc T−20..T−1)
- ONM20·ONM60 = 직전 20·60밤 r_on 평균
- FRN20 = 외인 코스피 현물 20일 순매수 합 / (매수+매도) 20일 합

## 8. 결론과 고정 사양

1. **A 에서 국면별 오버나잇 기대수익 차이는 약하게만 보인다.**
   - 추세·외인 수급 국면은 평균을 가르지 못했고, 하위 구간마다 부호가 뒤집혔다.
   - 일관되게 남은 것은 변동성 국면이다. 고변동성 국면의 밤 평균은 +6.8bp, 저변동성 국면은 +3.2bp 였다. 저변동성 국면에서는 프리미엄이 비용 5bp 를 밑돌아, 매일 보유가 비용 때문에 손실을 쌓는다.
   - 해석: "밤 프리미엄은 위험(변동성)에 비례하지만 비용은 고정"이다. 게이트는 기대 프리미엄이 비용을 넘을 가능성이 높은 밤만 남긴다.
   - 그 대가로 게이트 순샤프는 매일 보유 −0.04 에서 +0.28 로 오르고, MDD 는 −27.8% 에서 −11~14% 로 얕아진다(A, 5bp).
2. **약점**
   - 다중검정 뒤에는 유의하지 않다.
   - 7bp 비용에서는 보유 밤 순수익이 0 근처다.
   - 2008~09 같은 지속 하락·위기 국면에서는 고변동성 밤이 오히려 크게 잃었다(두 셀 모두 Δ −13~−16bp). 위기 국면에 대한 방어가 없다.
3. **셀 선택**
   - 1번 셀 **D3-USRV**(S&P500 20세션 실현변동성 백분위 ≥ 0.5)를 고른 이유: 적격 조건 전부 통과, H1·H2 균형, 지수 측정에서도 유지, 이웃 6개 모두 양수, 사전표본 2004~07 양수, 타 자산 3개 모두 양수. 경제적 근거도 가장 직접적이다(한국 밤의 위험 = 미국 정규장 위험).
   - 2번 셀 **D3-RVON**(KODEX 200 자체 오버나잇 20일 SD 백분위 ≥ 0.5)은 같은 가설을 거래 자산 자체의 오버나잇 위험으로 잰 반복 측정이다. 두 번째 셀의 사전 조건 — H1·H2·지수·2004-07 모두 Δ>0, 이웃 모두 양수 — 을 만족한다. 순샤프 최상위는 USRV AND RVON(0.30)이었지만 RVON 단독(0.28)과 차이가 0.02 에 불과했다. 그래서 단일 변수를 택했다. 이 "샤프 차 < 0.05 면 변수 적은 쪽" 규칙은 결과를 본 뒤 추가한 동점 처리임을 밝혀 둔다.
   - USTR200<.5 는 A 최고 t 였지만 2004~07 에서 음수, 2008~09 에서 크게 역전돼 제외했다.
   - 두 셀은 같은 가설의 두 측정이라 서로 독립적이지 않다. A 에서 게이트 값 일치율은 75%, 한쪽이 보유할 때 다른 쪽도 보유할 확률은 73% 다. B 에서 둘 중 하나만 통과하면 가설 확인으로 보기 어렵다.
   - 게이트 상태는 연 10~11회 바뀐다. 국면이 몇 주씩 이어지므로, 보유 밤이 연속으로 묶인다.
4. **B 확인 시 권고 판정**(사양에 기록, 판정자 재량): 판정 구간 B(2020-01-01~2025-06-05)에서 다음을 보고, 7bp 결과를 병기한다.
   - Δ > 0
   - 순샤프(5bp) > 매일 보유 순샤프
   - MDD 가 매일 보유보다 얕음
   - 보유 밤 순평균(5bp) > 0
