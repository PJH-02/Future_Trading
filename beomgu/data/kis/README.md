## 읽을 때 주의

- 선물 일봉의 front 는 만기 당일부터 차근월물로 넘어간다. 15차 v3 장부의 코스닥 밤 선물은 T 종가 → D 시가를 같은 계약으로 잡고, 만기 전날 밤만 만기물로 든다.
- 1분봉 time 은 봉 시작 시각이다. 정규일 411봉 = 08:45\~15:34 접속매매 410봉 + 15:45 마감 단일가 1봉. 08:45 봉 시가 = 개장 단일가 체결가. 15:35\~15:44 와 체결 없는 분은 봉이 없다(허봉 없음).
- 코스닥150 1분봉은 만기일(둘째 목요일)에 차근월물 하루 전체를 담고, 코스피200 1분봉은 만기일에 만기물(15:19 봉까지 395봉)을 담는다.
- TOSS·KODEX ETF 1분봉(끝 시각 라벨)과 맞출 때는 선물 time + 1분 = ETF 라벨.
- 2023.7.31 부터 선물 개장이 09:00 에서 08:45 로 바뀌었다. 그 전 일봉 시가는 09:00 단일가.
- 1분봉 거래량 합은 일봉 거래량보다 대체로 작다(중앙값 0.97). 정규장 체결분으로 쓴다.
- 지수 일봉의 volume·value_mil 은 응답값 그대로이고 코스닥150 지수의 초기 구간은 0 이다.
