# 전략 1 · 외국인 옵션 플로우 방향 신호

## 개요

외국인 투자자의 코스피200 옵션 콜/풋 순매수 금액을 Z-score로 정규화하여  
당일 KOSPI200 인트라데이 방향을 예측하는 전략.

- **진입**: 전일 신호 확인 → 당일 시가 매매
- **청산**: 당일 종가
- **비용**: 왕복 2bp (미니선물 기준)
- **판정 구간**: 2010-01-04 ~ 2026-09-17

---

## 핵심 발견

외국인의 콜/풋 플로우는 **비대칭** 정보를 가진다.

| 신호 | 방향 | Sharpe | 해석 |
|------|------|--------|------|
| 콜 z > 1.0 → 롱 | ❌ Sharpe **-0.26** | 콜 급매수는 역방향 (마켓메이커 델타헤지 추정) |
| 풋 z > 1.0 → 숏 | ✅ Sharpe **+0.37** | 풋 급매수는 하락 예측 신호 (헤지 or 방향성) |

→ **풋 Z-score만 유효한 방향 신호로 사용**

---

## 신호 계산

```
call_net(d)  = 외인 콜 매수금액(d) − 콜 매도금액(d)
put_net(d)   = 외인 풋 매수금액(d) − 풋 매도금액(d)

call_z(d) = (call_net − rolling_mean(60d)) / rolling_std(60d)
put_z(d)  = (put_net  − rolling_mean(60d)) / rolling_std(60d)

진입 신호 = put_z(T-1)   ← 전일 값 사용 (lookahead 없음)
```

## 케이스 정의

| 케이스 | 조건 | 방향 |
|--------|------|------|
| **A** | 풋z(T-1) > 0.5 | 숏 |
| **B** | 풋z(T-1) > 1.0 | 숏 |
| **C** | 풋z(T-1) > 1.0 **AND** 콜z(T-1) < 0 | 숏 |
| **D** | 풋z(T-1) > 1.0 → 숏 / 콜z(T-1) > 1.0 AND 풋z(T-1) < 0 → 롱 | 롱숏 혼합 |

## 전략 한계 및 개선 방향

- 샤프 ~0.37은 단독 사용보다 **다른 신호와 결합 시 필터로 활용**하는 것이 효과적
- `beomgu/t05_put_veto.py`의 오버나잇 거부권과 결합하면 시너지 기대
- 콜 급매수가 역방향인 이유: 외국인 마켓메이커의 델타 헤지 추정 → 추가 검증 필요
- 거래 비용 감소 시 A안(빈도 높음) 유리, 비용 증가 시 C안(정밀도 높음) 유리
