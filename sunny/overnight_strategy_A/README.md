# 오버나잇 전략 A · 외인 선물 수급 기반 종가 베팅

## 개요

당일 종가에 포지션을 잡고 익일 시가에 청산하는 오버나잇 전략.  
인트라데이 전략(1~3)의 수급 신호를 오버나잇 구조에 재적용하여 검증.

- **진입**: 전일 신호 확인 → 당일 종가 단일가
- **청산**: 익일 시가 단일가
- **비용**: 왕복 5bp (KODEX200 기준), 스트레스 7bp
- **판정 구간**: 2010-03-31 ~ 2026-10-30

---

## 핵심 발견

오버나잇 수익 구조는 인트라데이와 **다르다**.

| 신호 | 방향 | Sharpe | 해석 |
|------|------|--------|------|
| Base (항상 롱) | 롱 | **+0.57** | 오버나잇 자체에 강한 양의 드리프트 존재 |
| 외인 풋z > 1.0 → 숏 | ❌ **−0.42** | 풋 숏이 오버나잇에서 역방향 작동 |
| **외인선물z > 0.5 → 롱** | ✅ **+0.77** | 외인 선물 매수 = 오버나잇 갭업 예측 |
| 롱숏 결합 (D안) | +0.49 | C안보다 열위, 롱 단독이 우수 |

→ **핵심: C안 (외인 선물 z-score 롱 필터)**

---

## 신호 계산

```
fut_net(T)   = 외인 코스피200 선물 순매수 계약(T 장 마감 후 확정)
fut_z(T)     = (fut_net(T) − rolling_mean(60d)) / rolling_std(60d)

진입 신호     = fut_z(T-1)   ← 전일 값 사용 (룩어헤드 없음)
포지션: fut_z > 0.5 AND for_put_z < 1.5  → 롱
```

## 케이스 정의

| 케이스 | 조건 | 방향 |
|--------|------|------|
| **Base** | 항상 | 롱 (드리프트 기준선) |
| **A** | 외인 풋z > 1.0 | 숏 |
| **B** | 외인 풋z > 1.0 AND 개인 콜z > 0 | 숏 |
| **C** | 외인선물z > 0.5 AND 풋z < 1.5 | **롱 (핵심)** |
| **D** | B 조건 → 숏 / C 조건 → 롱 | 롱숏 혼합 |

## 인트라데이 전략과 비교

| | 전략 3C (인트라데이) | **오버나잇 C안** |
|--|-----------------|----------------|
| 구조 | 시가→종가 | **종가→익일시가** |
| Sharpe | 0.380 | **0.771** |

## 전략 한계 및 개선 방향

- **양의 드리프트 주의**: Base(항상 롱) Sharpe 0.57 → C안의 우수성이 선택 효과인지 알파인지 구분 필요
- **오버나잇 위험**: 갑작스러운 뉴스·이벤트 위험은 인트라데이보다 큼
- **개선 방향**:
  - SPX 실시간 방향 결합 (US 장 마감 후 ~06:00 KST 신호 추가)
  - 만기 주간 별도 필터
  - 변동성 레짐(VKOSPI) 조건부 규모 조정
