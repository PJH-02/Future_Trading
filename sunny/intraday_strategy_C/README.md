# 전략 3 · 외국인 vs 개인 옵션 방향 갈림 (스마트머니 vs 역지표)

## 개요

외국인(스마트머니)과 개인(역지표)의 옵션 방향이 엇갈릴 때 외국인 방향을 따르는 전략.  
두 투자자 그룹이 **반대 방향**으로 베팅할 때만 진입 → 신호 신뢰도 향상.

- **진입**: 전일 신호 확인 → 당일 시가 매매
- **청산**: 당일 종가
- **비용**: 왕복 3bp (키움증권 미니선물: 수수료 ~1bp + 슬리피지 ~2bp)
- **판정 구간**: 2010-03-31 ~ 2026-09-17

---

## 핵심 발견

개인 투자자 단독 역추세 전략은 **성립하지 않음**.  
외국인 풋 신호에 개인 콜 필터를 결합하면 **정확도가 향상**됨.

| 신호 | Sharpe | 해석 |
|------|--------|------|
| 개인 콜z > 1 → 숏 (A안) | **-0.205** | 개인 단독 역추세는 역방향 |
| 개인 풋z > 1 → 롱 (B안) | **-0.443** | 개인 패닉 단독도 안 통함 |
| **외인 풋z > 1 & 개인 콜z > 0 → 숏 (C안)** | **+0.380** | 이중 확인 신호 유효 |
| C + 롱 혼합 (D안) | +0.183 | C안 대비 열위 |

→ **C안 단독이 핵심**: 외국인은 풋 급매수(하락 예측) + 개인은 콜 순매수(낙관적) = 강한 숏 신호

---

## 신호 계산

```
for_put_net(d)  = 외인 풋 매수금액(d) − 매도금액(d)
ind_call_net(d) = 개인 콜 매수금액(d) − 매도금액(d)

for_put_z(d)   = (for_put_net  − rolling_mean(60d)) / rolling_std(60d)
ind_call_z(d)  = (ind_call_net − rolling_mean(60d)) / rolling_std(60d)

진입 신호 = for_put_z(T-1) > 1.0  AND  ind_call_z(T-1) > 0
           ← 전일 값 사용 (룩어헤드 없음)
```

---

## 케이스 정의

| 케이스 | 조건 | 방향 | 해석 |
|--------|------|------|------|
| **A** | 개인 콜z(T-1) > 1.0 | 숏 | 개인 FOMO 역추세 (단독) |
| **B** | 개인 풋z(T-1) > 1.0 | 롱 | 개인 패닉 역추세 (단독) |
| **C** | 외인 풋z(T-1) > 1.0 AND 개인 콜z(T-1) > 0 | 숏 | **이중 확인 (핵심)** |
| **D** | C 조건 숏 / 외인 콜z < -1 AND 개인 풋z > 1 → 롱 | 롱숏 혼합 | C + 롱 추가 |

## 전략 1과의 차이

| | 전략 1 (B안) | 전략 3 (C안) |
|--|-------------|-------------|
| 신호 | 외인 풋z > 1 | 외인 풋z > 1 **AND** 개인 콜z > 0 |
| 추가 필터 | 없음 | 개인 콜 순매수 (낙관적 분위기) |
| 진입 빈도 | 414일 | 198일 (절반) |
| 논리 | 외인 단독 | 외인+개인 **방향 갈림** 확인 |

## 전략 한계 및 개선 방향

- C안 198일 진입은 연평균 약 12일 → 빈도 낮아 실전 단독 운용 부담
- **전략 1 B안 + 전략 3 C안 결합** 시 서로 다른 날 진입 → 포트폴리오 효과 기대
- 개인이 왜 역지표 역할을 못 하는지 추가 검토 필요 (A·B안 모두 음수)
  - 가능한 이유: 개인은 옵션을 헤지보다 레버리지로 활용 → 방향성 없이 변동성 베팅
- 외국인 풋 신호의 해석 (전략 1 참고): 헤지 or 방향성 베팅 — 추가 검증 필요
