## 1. 연구 배경 및 가설

### 최초 가설
> 전일 KOSPI200 옵션시장 외인 콜/풋 매수세가 다음날 KOSPI200 현물 방향을 예측한다

### 1차 백테스트 결과 (기존 연구)
- 데이터: KRX 투자자별 거래실적, 2010.09~2026.09, 3,938거래일
- 지표: `CallFlow = (외인 콜 매수 - 매도) / (매수 + 매도)`, PutFlow 동일
- `OptFlow = CallFlow - PutFlow`

| 항목 | 결과 |
|------|------|
| β | +1.72 |
| HAC p-value | 0.26 |
| R² | 0.14% |
| 연 수익 플러스 | 17년 중 12년 |
| 옵션 단독 샤프 | 음수 |

**핵심 발견**
- 콜 매수세에는 정보가 거의 없음
- 외인 풋 순매수 다음날 약세 경향 (p=0.03)
- 전일 수익률, 외인 선물 수급 통제 시 유의성 사라짐
- **옵션 수급은 단독 1차 신호로 약함**

## 2. 전략 방향 전환: B안

### 설계 원칙
> 외인 선물 수급을 1차 신호로, 옵션 수급(풋 Z-score)을 2차 필터로 사용

```
1차 신호: 외인 선물 순매수 방향 (sign)
    ↓
2차 필터: 외인 풋 Z-score (미스프라이싱 강도)
    ↓
진입: 다음날 시가 / 청산: 당일 종가 (open-to-close)
```

### 케이스 정의
| 케이스 | 조건 |
|--------|------|
| Base | 외인 선물 순매수 방향만 |
| A | 선물 방향 + 옵션 방향 일치 시만 진입 |
| B | 선물 방향 + 풋 Z-score 방향 일치 AND \|Z\| ≥ 임계값 |
| C | A + B 동시 충족 |

### 신호 계산
```python
# 1차 신호
futures_signal = sign(선물_순매수)

# 옵션 플로우 정규화
total     = |콜_순매수| + |풋_순매수|
CallFlow  = 콜_순매수 / total
PutFlow   = 풋_순매수 / total
OptFlow   = CallFlow - PutFlow   # + = 콜 우세 (강세)

# 풋 Z-score (미스프라이싱 프록시)
put_zscore = (PutFlow - rolling_mean) / rolling_std  # 윈도우 60일
```

### 관찰
- 필터 추가할수록 거래횟수 감소, 최대낙폭 개선
- 전체 기간 양수 샤프 없음 → 선물 순매수 방향 단독 신호로는 부족
- Base 케이스: 연간 ~246회 거래 → 비용만 연 12% (샤프 악화 주요 원인)
- Close-to-open(오버나잇) 구조 테스트 → 전반적으로 open-to-close 대비 열위

## 6. 핵심 시사점 및 한계

**시사점**
- 옵션 수급 + 선물 수급 조합은 단독 대비 노이즈 감소 효과
- 풋 Z-score 필터(B안)가 최대낙폭 개선에 가장 효과적
- 1차 신호(선물)의 알파 자체가 부족한 것이 근본 원인

**한계**
- 매일 진입하는 구조 → 비용 부담 과다
- 외인 선물 순매수가 선물 방향을 단순 추종할 가능성
- 옵션 신호가 선물 신호의 후행 표현일 가능성
